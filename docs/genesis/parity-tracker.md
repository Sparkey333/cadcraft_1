## 6. Model continuity

The session that produced this work ran on the claude.ai/code session model; research workers, fact-checkers, reviewers and verifiers inherited it unless a record in `ai/training/iterations/` names another model. From 2026-10-22 all delegated work is pinned to the Opus 5.5 alias so the effort continues unchanged when the session model's limit is reached; the session model itself is switched by the owner in the session's model picker, not by the agent.

To continue in a fresh session: read `docs/genesis/README.md`, this tracker, and `docs/genesis/ai/learnings-log.md`; regenerate with the generator described in the README; append records for every run to `ai/training/iterations/` with the model that ran it; never edit CADCraft's own code or agent instructions without the owner's decision.
