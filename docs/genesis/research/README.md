> **Last reviewed:** 2026-10-21 · **Last updated:** 2026-10-21 · **Change:** major (first version)

JSON summary each worker returned (the page's tables are generated from the JSON). Every claim in
the notes carries the URL it was read from; items the worker could not confirm are marked

the page.

Access limits that shaped the notes: the research environment could reach most sites only through
search-result summaries (direct page fetches of autodesk.com, bricsys.com, g2.com, capterra.com,
reddit.com and the forums were refused by its network policy), and each worker had a limited
search budget. Counts and ratings are therefore "as indexed on 2026-10-21"; the page says so where
it matters. Nothing from any GPL-licensed CAD project's source code was read (clean-room rule).
