## 1. Survey & points — status: **full**

- **Survey database** (Toolspace Survey tab): networks, figures, control points, setups, observations; import via *Import Survey Data wizard* from field book (.fbk), point files (user-defined point file formats), drawing points, Survey LandXML; each import creates an Import Event; survey points are COGO points that live in the database and can only be edited there. https://help.autodesk.com/cloudhelp/2024/ENG/Civil3D-UserGuide/files/GUID-97D363BA-BAC2-4BAE-A2AA-C6C96C1CE8EF.htm
- **Adjustment & analysis**: traverse analysis (error of closure), **least squares analysis** (observation-equation method, 2D/3D, error ellipses), mapcheck analysis from labels or manual entry, figure inverse/mapcheck, export to field book and Survey LandXML. https://help.autodesk.com/view/CIV3D/2027/ENU/?guid=GUID-00FB26B1-BAB5-4190-B3FB-7FE3624E7F1E ; https://help.autodesk.com/view/CIV3D/2027/ENU/?guid=GUID-991229A5-5242-4B31-9628-3D429C0CC51B
- **Survey Data Collection Link** converts data-collector raw files to .fbk; forum reports say it realistically only handles older SurveyPro .job files — most firms export FBK/CSV from Trimble/Leica/Topcon software instead (unverified beyond forum posts). https://help.autodesk.com/cloudhelp/2023/ENU/Civil3D-UserGuide/files/GUID-4CE27FF4-A9F4-4B4C-9A17-E37564D46313.htm ; https://rpls.com/forums/topic/field-book-file-to-civil-3d
- **Point groups** (multiple membership, ordering governs style), **description key sets** (wildcards, map codes to styles/labels/layers/scale), point styles/labels, point file formats, point tables. https://vdci.edu/learn/civil-3d/understanding-description-keysets-in-civil-3d
- **Point clouds**: attach RCP/RCS (ReCap) via Insert > Point Cloud > Attach; *Create Surface from Point Cloud* with window/polygon/polyline area selection, non-ground filtering, decimation by point spacing; >2M points are subdivided. No direct LAS/LAZ/E57 import since 2018 — ReCap (Pro) required to convert. https://help.autodesk.com/view/CIV3D/2027/ENU/?guid=GUID-2F76077A-CA80-481F-B0D3-60BE636EF31C ; https://www.autodesk.com/support/technical/article/caas/sfdcarticles/sfdcarticles/How-to-import-point-clouds-in-Civil-3D-without-using-ReCap.html
- Gap: Autodesk explicitly recommends not collaborating on a survey database in Forma Data Management with Desktop Connector 16.x (copy locally, upload back). https://help.autodesk.com/view/CIV3D/2027/ENU/?guid=GUID-4B28D9A3-AD1B-453D-8000-0B2ECA58A487

## 2. Surfaces — status: **full**

- TIN and grid surfaces; volume surfaces (TIN volume / grid volume = difference between two surfaces); definition items: points, point groups, DEM files (AddSurfaceDEMFile, CreateSurfaceGridFromDEM), drawing objects, breaklines (standard/proximity/wall/non-destructive), boundaries (outer/hide/show/data clip), contours, edits (swap edge, delete line, add/delete points, raise/lower, smoothing, simplify, paste surface, crop). https://help.autodesk.com/cloudhelp/2023/ENU/Civil3D-UserGuide/files/GUID-1BFB673D-F667-410A-9400-0FAABEB5951C.htm ; https://help.autodesk.com/cloudhelp/2016/ENU/Civil3D-UserGuide/files/GUID-DB28F66C-41F2-4171-8F9A-BB549DF3362E.htm
- **Analyses**: directions (aspect), elevations (banding), slopes, slope arrows, contours, user-defined contours, **watersheds** (drain targets: boundary point, boundary segment, depression; TIN triangles split so each watershed is whole triangles), contour problems, **water drop** path. https://help.autodesk.com/view/CIV3D/2027/ENU/?guid=GUID-C8D8B7E2-D2E5-460A-ABE7-C4131C85295E ; https://help.autodesk.com/view/CIV3D/2027/ENU/?guid=GUID-E021850D-0749-42CC-A49E-6C8BB6CC1DC8
- **Volumes**: composite (TIN-to-TIN) volume surfaces, bounded volumes, Volumes Dashboard with cut/fill factors; sectional volumes via sample lines (see §8). https://help.autodesk.com/cloudhelp/2016/ENU/Civil3D-UserGuide/files/GUID-DB28F66C-41F2-4171-8F9A-BB549DF3362E.htm
- **LandXML**: schema 1.0/1.1/1.2 supported; surfaces (TIN & grid incl. source data), points/point groups, alignments (lines/curves/spirals, superelevation, cant, station equations), profiles, parcels, pipe networks (pressure networks NOT supported for LandXML), corridors (export as Roadways), feature lines, survey. LandXML 2.0 not mentioned. https://help.autodesk.com/view/CIV3D/2027/ENU/?guid=GUID-C77216E8-09FA-4D63-8182-400E9C2DB0A4 ; https://help.autodesk.com/view/CIV3D/2027/ENU/?guid=GUID-4D10ABA5-5EA0-41A8-BB61-C3F446CE7C6B ; https://www.autodesk.com/support/technical/article/caas/sfdcarticles/sfdcarticles/Unable-to-Export-or-Import-Pressure-Network-in-Civil-3D.html
- **DEM/GIS**: DEM (GeoTIFF/USGS), surfaces from GIS datastores (CreateSurfaceFromGIS), ReCap-exported DEM TIF route for lidar. https://resources.imaginit.com/civil-3d/prepare-usgs-lidar-data-in-recap-for-import-to-civil-3d
- 2026: **partial-surface data references** (reference boundary polyline; publish partial to Autodesk Docs; LandXML export; API). https://help.autodesk.com/view/CIV3D/2026/ENU/?guid=GUID-2E278ED0-CA19-4DDE-A82F-81EDCF9E45AC
- Known pain: large LandXML surface import can be slow/fatal; Autodesk advises turning off "Create Source Data in Drawing", cropping, simplifying, and using data shortcuts. https://www.autodesk.com/support/technical/article/caas/sfdcarticles/sfdcarticles/Slow-performance-when-importing-LandXML-surface-into-Civil-3D.html

## 3. Parcels & COGO — status: **full** (legal-description writer is basic: **partial**)

- Sites/parcels topology: parcels form only from closed segment loops; parcel segments from lines/curves/polylines; **Parcel Layout Tools**: slide line (create/edit), swing line, free-form create, automatic subdivision by minimum area/frontage/frontage offset/min width/min depth/max depth, PI tools, parcel union/dissolve. https://help.autodesk.com/cloudhelp/2024/ENG/Civil3D-UserGuide/files/GUID-E57675BB-8D82-4D51-9C43-93B2B680AAED.htm ; https://blog.nobledesktop.com/learn/civil-3d/automatic-subdivision-parcel-creation-methods-in-civil-3d
- Labels: area labels, segment labels (bearing/distance, crow's feet), line/curve tables, parcel tables; styles.
- **Map check / inverse**: Export Parcel Analysis (inverse or mapcheck, across-chord, CW/CCW, error of closure), Map Check Report (parcels or survey figures, POB override, truncate area), survey Mapcheck Analysis from labels. https://help.autodesk.com/view/CIV3D/2027/ENU/?guid=GUID-F0235665-F79C-4D27-A3FD-6237861B4807 ; https://help.autodesk.com/view/CIV3D/2027/ENU/?guid=GUID-3D99202F-BDD3-4585-89E1-02DE47ECFD3A
- **Legal descriptions**: Toolbox > Reports Manager > Parcel > *General Legal Description Report* (phrasings editable in `GeneralLegalPhrasings.xml`), *Metes and Bounds Report* (alignment, parcel, or survey figure). Output is XSL-driven HTML/PDF/TXT/XLS/DOC; users report it is rigid (POB/direction control weak), so many use Trimble Business Center, Carlson, or App Store add-ins. https://help.autodesk.com/view/CIV3D/2027/ENU/?guid=GUID-29D1CA8E-07A6-4A6B-B889-F92FA679DC3F ; https://www.autodesk.com/support/technical/article/caas/sfdcarticles/sfdcarticles/Where-to-change-legal-description-report-phrasings-in-Civil-3D.html ; https://rpls.com/forums/software-cad-mapping/c3d-legal-descriptions-from-parcels/
- COGO: transparent commands (bearing/distance, station/offset, etc.), COGO editor, lines/curves by many methods, point creation tools.

## 4. Alignments & profiles — status: **full**

- Alignment types: centerline, offset (dynamic), curb return, rail, miscellaneous; layout tools (fixed/floating/free tangents, curves, spirals incl. clothoid/Bloss/sinusoidal etc.), best-fit, station equations, design speeds.
- **Criteria-based design**: design criteria file (XML) with minimum radius tables, superelevation rate/transition tables, attainment methods (AASHTO 2001/2004/2011 and country kits); design checks (user formulas in design check sets); violations flagged with warning glyphs/tooltips in plan, profile and Project Explorer. https://help.autodesk.com/cloudhelp/2024/ENG/Civil3D-UserGuide/files/GUID-E08E8F60-5BF1-4188-8A15-901646DF8F62.htm ; https://help.autodesk.com/view/CIV3D/2027/ENU/?guid=GUID-3715DBC3-15E9-484D-9A0E-0DFF49707BA8
- **Superelevation** wizard: roadway types (undivided crowned/planar, divided crowned/planar with median), pivot methods, lanes/shoulders, rate table or "by formula", curve smoothing, overlap resolution; Superelevation Curve Manager & tabular editor; superelevation views; rail **cant**. https://help.autodesk.com/view/CIV3D/2027/ENU/?guid=GUID-43CA7259-D1EF-46F4-B6B1-F2A7F112446D ; https://www.autodesk.com/support/technical/article/caas/sfdcarticles/sfdcarticles/How-to-customize-the-superelevation-attainment-methods-and-table-in-Civil-3D.html
- Profiles: surface profiles (dynamic to surface), layout profiles with PVIs, circular/parabolic/asymmetric vertical curves, K-value checks, profile views with bands, projection of objects into profile views.
- **Horizontal Regression Analysis** (2026.1, improved 2026.2/2027): best-fit tangents/curves/spirals to COGO points/feature lines/polylines, slew thresholds. Known 2027 UI issues (blinking dialog, negative design speed allowed). https://help.autodesk.com/view/CIV3D/2027/ENU/?guid=civil_3d_known_issues_2027

- **Project Explorer** (included; Add-ins tab): tabbed live view of alignments/profiles/corridors/pipes/feature lines etc., design-rule warning tooltips, multi-object editing (multiple part swap, pipe-run slope editor, assembly width edits), template-driven reports to PDF/XLSX/DOCX, object sets with versioned output history, 2D DWG export. https://help.autodesk.com/view/CIV3D/2027/ENU/?guid=GUID-A7576278-F107-4FB5-9011-B98229BA888C

## 18. Honest summary of strengths / weaknesses (for the comparison)

Unique strengths: de-facto industry standard with DOT/country kits and agency templates; deepest end-to-end land-dev chain (survey → surface → parcels → alignments/profiles → corridors → grading → pipes/drainage → sections/QTO → sheets) in one DWG-native product; dynamic object model; integrated drainage analysis (2026.2+) and optimizer; Dynamo + .NET + COM/LISP automation; Project Explorer reporting; AEC Collection bundle (InfraWorks, Revit, Navisworks, ReCap); in-product AI assistant (preview).

Notable weaknesses: Windows-only, heavy hardware; subscription-only pricing (~$2.9–3.2k/yr standalone, $3.7k Collection) with yearly increases; AECC objects not backward compatible (no "save to previous" for Civil objects; proxies; LandXML the only escape hatch); data shortcuts/xrefs break when files move, permissions differ or paths are long — Autodesk's answer (Connected References) is cloud-gated behind Forma Design Collaboration; cloud collaboration is file-locking, single-editor, Desktop-Connector dependent, with explicit unsupported areas (survey DB, SSM, reference templates); stability complaints persist (2027 fixed-issue list itself documents multiple crashes in feature lines, grading, corridors, drainage); steep learning curve; SSA discontinued mid-transition (cloud-only replacement requires sign-in/entitlement); MrSID dropped; plug-ins must be recompiled for .NET 10; no sustainability (solar/rain/carbon) tooling in-product.
