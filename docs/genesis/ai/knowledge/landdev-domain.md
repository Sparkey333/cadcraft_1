# Land development and site design: domain knowledge

Gathered 2026-10-21 from agency guidance, standards and practitioner sources; priorities are the Genesis plan's.

## Summary

A simplified but complete land-development CAD must carry a project from feasibility (parcel, zoning, flood, wetlands, soils, slopes) through survey import, site planning with live zoning and ADA checks, grading with cut/fill balance, hydrology and stormwater sizing, utilities, road and parking geometry, landscape, recordable plats and construction-document sheet sets, to stake-out and as-builts. Today each stage uses two to four tools (Civil 3D with Hydraflow/SSA, Carlson, Trimble Business Center, HydroCAD, Bluebeam, GIS, spreadsheets) joined by DXF/LandXML/CSV/PDF hand-offs where CRS, attributes and references get lost. Must-haves: CRS-aware drawing, COGO points and traverse/mapcheck, parcels with legal descriptions, TIN surfaces with contours and volumes, feature-line grading, Rational/SCS hydrology with Atlas 14 rainfall, pipe networks with crossing checks, alignments and profiles, a parametric zoning rule engine, sheet sets with revision clouds, LandXML/DXF/GeoTIFF/GeoJSON exchange, a project container with link health and provenance, and a never-crash policy. Each old-school and neo technique listed below reduces to a few object types, calculations, data feeds and reports. Nearly all needed US data are public domain or permissive with verified endpoints; OSM (ODbL), NSRDB (CC BY 3.0 US), EPSG (acknowledgement) and ICC code text (copyright) need care. Caveat: the search budget ran out early and official hosts were egress-blocked, so verification came from GitHub code search, AWS open-data registry licence lines and the Autodesk Help API; unverified items are marked.

## Requirements

| Area | Requirement | Priority | Why | Data source |
|---|---|---|---|---|
| Geodesy | Drawing CRS (EPSG), grid-to-ground scale factor, vertical datum tag, reprojection of imports, bearing/azimuth/DMS input, US survey vs international foot | must | Every survey and data feed is in a different CRS; this is where off-by-a-foot errors come from | EPSG dataset via PROJ proj.db; https://epsg.org/terms-of-use.html |
| Points/COGO | COGO point object (number, N, E, Z, description), point groups, description keys, CSV/PNEZD/LandXML import-export | must | Survey data enter and leave as points |  |
| Points/COGO | Bearing-distance, inverse, intersections, traverse with closure and compass-rule adjustment, mapcheck report | must | Boundary work and plat checking; reference behaviour is Civil 3D Map Check Report | https://help.autodesk.com/view/CIV3D/2026/ENU/?guid=GUID-3D99202F-BDD3-4585-89E1-02DE47ECFD3A |
| Parcels | Parcel object with area, line/curve tables, lot numbering, ROW parcels, generated metes-and-bounds description with editable phrasing | must | Plats and legal descriptions are deliverables on every subdivision | https://www.autodesk.com/support/technical/article/caas/sfdcarticles/sfdcarticles/Where-to-change-legal-description-report-phrasings-in-Civil-3D.html |
| Surfaces | TIN from points, breaklines, contours, GeoTIFF DEM, LandXML; boundaries/holes; contours with interval, index, smoothing, labels; spot elevations; slope/elevation banding | must | Existing and proposed ground underlie grading, drainage and volumes |  |
| Surfaces | Surface-to-surface volumes (TIN difference) plus grid and average-end-area for reconciliation, labelled by method | must | Contractors and reviewers compare methods; results differ (Autodesk support note) |  |
| Surfaces | LAS/LAZ point-cloud import with ground-class filtering | should | 3DEP and drone lidar are the cheapest topo for feasibility | USGS 3DEP LPC (LAZ 1.4) |
| Grading | Feature lines with elevations/grades, slope-to-surface daylight, pad and parking grading, retaining wall TW/BW, live cut/fill balance | must | Core of site design; model is Civil 3D grading groups |  |
| Grading | ADA route checker (running <= 5%, cross <= 2%, ramps <= 1:12 with landings) and accessible parking count from Table 208.2 | must | Plan reviewers reject sets on these; today checked by hand | https://www.ada.gov/law-and-regs/design-standards/2010-stds/ |
| Drainage | Drainage areas with Tc, Rational and SCS-CN runoff (CN from SSURGO HSG), Manning pipe sizing, HGL/EGL on profiles, inlet spread, pond stage-storage-discharge with simple routing | must | Minimum to produce a drainage report | SSURGO muaggatt.hydgrpdcd via https://sdmdataaccess.sc.egov.usda.gov/tabular/post.rest |
| Drainage | NOAA Atlas 14 point fetch stored in the project with provenance | must | Design storms for every hydrology calc; must not be re-fetched silently | https://hdsc.nws.noaa.gov/cgi-bin/hdsc/new/cgi_readH5.py?lat=&lon=&type=pf&data=depth&units=english&series=pds |
| Drainage | LID/BMP objects sized to WQv; SWPPP disturbed-area and phasing tally; E&SC symbol library | should | NPDES construction permits above 1 acre (unverified threshold) and MS4 reviews require them |  |
| Utilities | Gravity pipe networks (structures, pipes, inverts, slopes, cover, rims), plan/profile labels, crossing and clearance report | must | Sanitary and storm plans and profiles are mandatory sheets |  |
| Roads | Horizontal alignments (tangent, circular curve), stationing, profiles with vertical curves, cross sections | must | Driveways, streets, utility stationing |  |
| Site rules | Parametric zoning rule set (setbacks by yard, impervious %, coverage, height, parking ratios, buffers, well/septic/stream setbacks) with live compliance report | must | Genesis differentiator; done in spreadsheets today and a top source of resubmittals |  |
| Sheets | Layouts/viewports, sheet index, title-block fields, revision clouds with deltas, north arrow and scale bar objects, match lines, batch PDF with bookmarks | must | Construction documents are the product |  |
| Sheets | Plat template (certificates, monument legend, line/curve tables) at recording sizes | should | Recordable plats have county-specific formats |  |
| Exchange | DXF/DWG, LandXML 1.2 (surfaces, alignments, profiles, parcels, CgPoints, pipes), GeoJSON/GeoPackage/shapefile, GeoTIFF, CSV, PDF out | must | Every hand-off in the workflow table uses one of these |  |
| Referencing | Project container bundling drawing, references and data snapshots with relative paths, link-health check and per-layer provenance (URL, date, licence, attribution) | must | Stated Genesis goal; ODbL/CC-BY attribution is also a legal need |  |
| Referencing | Live connectors with caching to NFHL, NWI, SSURGO, 3DEP, Atlas 14, parcels, OSM | should | Feasibility maps in minutes instead of a GIS detour |  |
| Stability | Never-crash policy, autosave/journaling, recovery, hostile-input tests for every parser | must | Zero-crash goal; parsers of external data are the main risk |  |
| Neo | Sun-path/shadow study, PV layout and PVWatts v8 call; rainwater catchment and cistern sizing; septic sizing; defensible-space rings; BFE/freeboard check | should | Cheap to add on top of surfaces and rules; strong differentiator for owner-builders and permaculture designers |  |
| Roads | Spirals, superelevation, corridors/assemblies, least-squares survey adjustment, dynamic routing via EPA SWMM, 3D visualisation | later | Highway- and survey-firm-grade features; not needed for a first permit set |  |

|---|---|---|

| Cisterns and rain catchment | Catchment object (roof polygon, pitch, efficiency), downspout routing, cistern object (volume, overflow, first flush), calc gallons = ft2 x inches x 0.623 x efficiency, monthly mass balance vs demand | 0.623 constant e.g. github.com/PDFCraftTool/OmniTools; TWDB Rainwater Harvesting Manual https://www.twdb.texas.gov/publications/brochures/conservation/doc/RainwaterHarvestingManual_3rdedition.pdf (unverified) |

| Passive solar siting and orientation | Sun-path diagram and solar altitude/azimuth for date and place (implement Reda-Andreas SPA from the NREL report, not NREL's C code), long-axis orientation check, overhang depth from sun angles, shadow casting from terrain/trees/neighbours | NREL/TP-560-34302 as transcribed in pvlib spa.py (github.com/pvlib/pvlib-python); https://www.energy.gov/energysaver/passive-solar-home-design (unverified) |
| Swales, terraces and keyline | Trace-contour-at-elevation, near-contour polylines draped on surface with a set fall (keyline ~1:400), terrace spacing from slope, swale cross-section cut/fill, spillway points | NRCS CPS 600/412/362 (CPS numbering confirmed via github.com/HiCSC/ClimateSmartPracticeStandards); Yeomans keyline (unverified) |
| Dry-stone walls | Wall object with batter (~1:6), base width about half to two-thirds of height, height limit, through-stone courses, tonnage estimate | Dry Stone Walling Association https://www.dswa.org.uk/ (unverified) |
| Earth building: adobe, rammed earth, cob | Thick-wall object (cob 12-24 in), stem-wall height above grade, roof-overhang rule, one-storey prescriptive limit flag per IRC Appendix AU, formwork lift heights for rammed earth | 2021 IRC Appendix AU via github.com/thexqin/us-building-codes-dataset; NM 14.7.4 NMAC, ASTM E2392 (unverified) |
| Timber framing | Bent/bay grid, post/beam/brace library, pier and footing layout on the site plan, crane and laydown areas | Timber Framers Guild https://www.tfguild.org/ (unverified) |
| Straw bale and light straw-clay | Modular thick wall (18-24 in) with bale course counts, toe-up height, roof overhang, one-storey prescriptive flag per IRC Appendix AS; infill-only flag per Appendix AR | 2021 IRC Appendices AS and AR via github.com/thexqin/us-building-codes-dataset |
| Windbreaks and shelterbelts | Linear planting object with species rows, spacing, mature height H, orientation to prevailing wind, protected-area polygon (~10 H downwind), NOAA wind rose input | NRCS CPS 380 Windbreak/Shelterbelt Establishment and Renovation, via github.com/HiCSC/ClimateSmartPracticeStandards |
| Septic systems and leach fields | Tank and drainfield trench objects, area from percolation rate and bedrooms (state tables), setbacks to wells/lines/water/foundations, reserve area, plan and profile | EPA Onsite Wastewater Treatment Systems Manual EPA/625/R-00/008 (unverified) |
| Wells | Well point with setback rings and well-log attributes; link to USGS NWIS groundwater levels and state well-log databases | NWIS endpoint https://waterservices.usgs.gov/nwis |
| Magnetic bearings in old deeds | Declination for date and place to rotate magnetic calls to true or grid north | NOAA NCEI geomagnetic calculator https://www.ngdc.noaa.gov/geomag/calculators/magcalc.shtml (unverified) |
| PLSS township/range/section descriptions | Aliquot-part generator and BLM CadNSDI PLSS grid import | https://gbp-blm-egis.hub.arcgis.com/ (unverified) |
