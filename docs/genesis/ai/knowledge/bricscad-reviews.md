# BricsCAD: what users praise and curse

Paraphrased user opinions gathered 2026-10-21; every item carries the URL it came from. Severity: high = loses work, money or days; medium = hours; low = irritation.

## Summary

User sentiment 2024-2026 is positive on the volume sites (G2 4.5/5 on 135 reviews; SaaSWorthy 4.7/5 on 131) and the pitch that works is 'AutoCAD-compatible, much cheaper, perpetual licence still sold'. The loudest negatives are stability regressions in each yearly release (V25.1-25.2 panning/autosave crashes with an MTFLAGS=0 workaround, users rolling back to meet deadlines; V26.1.08 more crashes on macOS), a macOS build users call a 'perpetual beta' (freezing, no clear native Apple-silicon binary, Metal renderer slower than OpenGL), a second-class Linux build (Wayland black window), large-drawing/3D performance, dynamic blocks (creation only arrived in V26, experimental and unavailable to US users for licensing reasons), uneven support responsiveness (Capterra support 3.9 vs ease-of-use 4.6), and a January-2026 upgrade/support policy that forum users call a 'cynical move' against old perpetual licences. No direct user reviews of the native civil tools surfaced; the market treats a third-party add-on (Civil Site Design) as the Civil 3D alternative on BricsCAD, implying the native TIN/alignment/corridor stack is incomplete for site design. LIMITS: ten searches only (shared budget exhausted) and every target host was denied by the environment's network policy, so all items are paraphrased from search-engine summaries, not opened pages; no Reddit or Hacker News threads were captured; BIM usability and LISP-compatibility themes were not reached.

## What users wish for

- A stable x.0 release each year - stop shipping regressions that force users to roll back (V25.1/25.2 crash threads).
- A native Apple-silicon macOS build with Windows feature parity and a Metal renderer no slower than the old OpenGL path.
- Full Wayland support and polished Linux desktop integration.
- Better large-drawing, Structure-Browser and 3D-viewport performance.
- Dynamic-block creation available to all users including the US, and out of 'experimental'.
- The remaining missing or less-polished AutoCAD commands closed.
- Keep affordable perpetual upgrades for old licences; stop raising maintenance; no push to subscription.
- Faster, more reliable support tickets and licence/registration handling.
- More tutorials, documentation and a larger community.
- A plug-in API (.NET/BRX/LRX) that does not break at each yearly version.
- Less dated UI and better rendering.
- (Inferred) native civil tools complete enough for site design without a third-party add-on.
