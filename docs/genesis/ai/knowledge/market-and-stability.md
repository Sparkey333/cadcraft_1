# Market, pricing, business models; stability and referencing pain across CAD

Paraphrased user opinions gathered 2026-10-21; every item carries the URL it came from. Severity: high = loses work, money or days; medium = hours; low = irritation.

## Summary

Civil/infrastructure design software is a ~USD 2-4 B/yr market growing ~7%/yr (analyst figures disagree by 60%). Serious civil tools cost USD 1.2k-6k per seat per year; Autodesk, Vectorworks, SketchUp and Land F/X are subscription-only, leaving BricsCAD, Carlson, 12d, Bentley (at ~2.5x annual) and Trimble dongles as the last perpetual options - the clearest pricing gap. Open-source tools live on small recurring donations plus a few corporate patrons (Blender: ~EUR 3.1 M income in FY2024 yet a loss), low-priced pro builds (QCAD, Krita store builds, Ardour pay-what-you-want) or a separate services company (Godot/W4); the VC-backed FreeCAD company Ondsel shut down in Dec 2024 (unverified). On stability, Autodesk's own release notes list 10-17 crash/hang fixes per Civil 3D point release through 2026-2027, its knowledge base has a separate FATAL ERROR article per workflow, and references are path strings in DWGs and per-user XML files that break on every move, rename, drive mapping, permission or cloud-cache difference; each mitigation (autosave, .bak, Recovery Manager, Reference Manager, eTransmit, Bind, Desktop Connector) carries documented fine print, and cloud worksharing turns 'file not found' into 'local changes discarded'. Caveat: the shared search budget ran out after 12 searches and page fetches were proxy-blocked, so BricsCAD/Bentley/Vectorworks crash evidence and several funding pages are unverified; Autodesk evidence comes from the official Autodesk help tool and sibling notes.

## What users wish for

- Business: free, perpetual, open desktop app; monetise a paid hosted project container + link-health service only after the desktop tool is in daily use (Ondsel lesson); paid support/training for firms and municipalities; sponsorship from survey-hardware, workstation and GPU vendors plus a small-donor programme (Blender model); later a plug-in marketplace; never dual licensing or core feature paywalls.
- Stability: keep CADCraft's no-panic/catch_unwind/hostile-test discipline and add a CI gate on every PR; atomic saves with N-generation backups and a continuous change journal instead of a resettable 10-minute timer; autosave on web; per-object integrity hashes always on.
- Stability: sandbox plug-ins (separate process or WASM) so add-ins, enablers and runtimes cannot take the host down; opt-in crash telemetry that files a reproducible report with the drawing excerpt.
- Files: no RegApp/NOD-style bloat by construction, deterministic save, per-table size report; documented versioned object schema with forward and backward readers so 'save to older version' exists from day one.
- Referencing: references by content identity plus project-relative path recorded in a project manifest (xrefs, data links, images, fonts, templates, plot styles with hash/size/mtime/role); relocation, packaging (fonts, patterns, linetypes included) and eTransmit become a manifest copy.
- Referencing: a linkcheck command reporting found/missing/refused/changed-since-load for every nested link, a file watcher raising 'reload available', persisted reference state (Unloaded, found-at), colour-coded link health in the palette.
- Collaboration: shared design objects referenced by ID through the manifest rather than per-user XML path files; explicit lock/merge semantics; local-first sync that never discards local work (keep both versions on conflict).
- Containment: one movable project folder; copy = deep copy with link rewrite; paste/insert/bind merge rules (existing name wins, anonymous names regenerated) shown in a preview so nothing changes silently.
